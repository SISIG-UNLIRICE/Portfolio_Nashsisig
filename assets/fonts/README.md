# Portfolio fonts

These are the existing portfolio typefaces, downloaded from the official
[Google Fonts repository](https://github.com/google/fonts/tree/main/ofl).
Each family is distributed under the SIL Open Font License 1.1; its license is
included alongside the font files. No font outlines were modified.

Source directories: `megrim`, `londrinasolid`, `lora`, `kavivanar`, `kumarone`,
and `juliussansone` under `ofl/`. Lora's `[wght]` filenames were renamed to
`-Variable` for simple static asset URLs. `fonts.css` uses local relative paths,
so the site does not depend on third-party font requests.
